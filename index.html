01. About Me

I transform complex, unstructured datasets into clear visual narratives and predictive models. My approach combines rigorous Exploratory Data Analysis (EDA) with practical statistical validation to unlock actionable business intelligence.

With experience across synthetic dataset generation and automated preprocessing pipelines, I focus on building reliable data foundations that drive real-world decision-making.

I specialize in training and deploying machine learning models using Scikit-Learn, NLP algorithms, and computer vision frameworks. My experience spans end-to-end sentiment classifiers, phishing detectors, and YOLO object detection models.

Active as a Kaggle Dataset and Notebook Expert, I regularly engineer high-impact data models and refine hyperparameter tuning pipelines for maximum accuracy.

Machine learning models are only as good as their accessibility. I bridge backend data models with responsive user interfaces using React, Vite, Tailwind CSS, and Flask.

Whether building custom AI writing assistants, interactive whiteboards, or real-time streaming platforms, I prioritize scalable architecture, smooth state management, and intuitive UX design.
